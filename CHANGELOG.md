# История изменений

## 1.2.1

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 1.2.0

- Текущая рабочая версия перенесена под название LipatoS.
- Добавлен отдельный тумблер редактирования вкладки «Биография» для игроков.
- Режим редактирования применяется только к части `biography` листа персонажа.
- Остальные разделы листа персонажа не разблокируются.
- При завершении редактирования последнее активное поле корректно теряет фокус перед перерисовкой.
