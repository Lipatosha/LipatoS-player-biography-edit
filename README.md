# LipatoS — Редактирование биографии игроком

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который позволяет обычным игрокам редактировать только вкладку **«Биография»** своего персонажа.

Игрок включает отдельный тумблер прямо на вкладке биографии. При этом остальные разделы листа персонажа не переходят в режим редактирования.

## Версия

**1.2.1**

## Совместимость

- Foundry VTT: **14.367**
- D&D 5e: **6.0.0–6.0.5**

## Возможности

- добавляет игроку отдельный тумблер редактирования вкладки **«Биография»**;
- разрешает редактирование только части `biography`;
- не разблокирует остальные разделы карточки персонажа;
- работает только для принадлежащего игроку персонажа типа `character`;
- при выключении режима сохраняет последнее изменение перед перерисовкой;
- для ГМ модуль ничего не меняет.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-player-biography-edit/main/module.json`
